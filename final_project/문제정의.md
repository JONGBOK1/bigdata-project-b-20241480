# 프로젝트 문제정의

## 1. 선택한 데이터
- **이름**: 학생 중퇴율과 학업 성공률 예측 데이터셋
- **출처(URL)**: https://www.kaggle.com/datasets/thedevastator/higher-education-predictors-of-student-retention
- **라이선스**: CC BY 4.0
- **크기**: 약 4,424행 × 37열
- **형식**: CSV
- **어떻게 받았나**: Kaggle에서 직접 다운로드

## 2. 풀고 싶은 문제
- **한 문장으로**: "포르투갈 고등교육 학생 데이터로 학생의 중퇴 여부(Dropout/Graduate/Enrolled)를 예측하고 싶다"
- **예측/분류 대상(target)**: `Target` 컬럼 — Dropout(중퇴), Graduate(졸업), Enrolled(재학중) 3분류

## 3. 만들 서비스(완성 모습)
- **사용자가 무엇을 입력하면**: 학생의 입학 정보(나이, 전공, 성적, 학비 납부 여부 등) 입력
- **무엇을 보여주는 앱인가**: 해당 학생이 중퇴할 가능성 / 졸업 가능성 예측 결과 + 위험 요인 시각화
- **사용할 기술**: ML (scikit-learn RandomForest 분류)

## 4. 예상 난관 1가지
- 다중 분류(3개 클래스)에서 "Enrolled(재학중)" 클래스는 아직 결과가 나오지 않은 학생이라 학습 데이터로 사용 시 노이즈가 생길 수 있음
- 해결 방안: Dropout vs Graduate 이진 분류로 단순화하거나, Enrolled를 제외하고 학습
