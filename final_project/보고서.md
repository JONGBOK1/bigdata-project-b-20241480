# 보고서 — 학생 중퇴율 & 학업 성공률 예측

## 1. 문제정의
포르투갈 고등교육 기관의 학생 4,424명 데이터를 사용하여,
학생이 **중퇴(Dropout)** 할지 **졸업(Graduate)** 할지 예측하는 분류 모델을 개발한다.

**목표**: 중퇴 위험 학생을 조기에 식별하여 학교가 선제적 지원을 제공할 수 있도록 돕는다.

---

## 2. EDA 발견

| 발견 | 상세 내용 |
|------|-----------|
| 결측값 없음 | 37개 컬럼 모두 결측 없이 완전한 데이터 |
| 타겟 불균형 | Graduate 49.9%, Dropout 32.1%, Enrolled 18.0% |
| 핵심 변수 | 학비 납부 여부, 1·2학기 성적 및 이수 과목 수 |
| 나이 효과 | 입학 나이가 30세 이상인 만학도에서 중퇴율 급증 |
| 장학금 효과 | 장학금 수혜 학생의 졸업율이 비수혜 학생 대비 약 2배 |

---

## 3. 모델

- **알고리즘**: Random Forest Classifier (n_estimators=100)
- **학습 데이터**: Dropout + Graduate만 사용 (Enrolled 제외)
- **분류 방식**: 이진 분류 (Dropout=0, Graduate=1)
- **Train/Test 비율**: 80/20, stratified split

### 성능 결과
| 지표 | 중퇴 | 졸업 |
|------|------|------|
| Precision | ~0.87 | ~0.89 |
| Recall | ~0.85 | ~0.91 |
| F1-score | ~0.86 | ~0.90 |
| **정확도** | **~88%** | |

### 특성 중요도 (상위 5개)
1. 2학기 이수 과목 수
2. 1학기 이수 과목 수
3. 2학기 평균 성적
4. 1학기 평균 성적
5. 학비 납부 여부

---

## 4. 결론

- **초반 학업 성취도**(1·2학기 성적 및 이수 과목)가 중퇴 예측에서 가장 중요
- **재정 상태**(학비 납부, 장학금, 채무)도 큰 영향
- MVP 달성: 학생 정보 입력 → 중퇴 확률 예측 → 위험 요인 안내

## 5. 한계

- 포르투갈 특정 학교 데이터이므로 다른 교육 환경에 일반화 어려움
- Enrolled(재학중) 학생을 학습에서 제외하여 실제 현황 반영 미흡
- 학과별 난이도 차이가 성적에 미치는 영향 미반영
