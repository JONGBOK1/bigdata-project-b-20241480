## 1. 문제 정의

대학교에서 학생의 중퇴는 학생 본인은 물론 교육 기관에도 큰 손실이다. 만약 중퇴 위험이 높은 학생을 사전에 파악할 수 있다면, 교수·상담사·학교 행정팀이 조기에 개입하여 중퇴를 예방할 수 있다. 본 프로젝트는 포르투갈 고등교육 학생 데이터를 활용해 **학생이 중퇴할 가능성을 예측하는 웹 서비스**를 구축하는 것을 목표로 한다.

- **예측 대상(Target)**: 중퇴(Dropout) vs 졸업(Graduate) 이진 분류
- **서비스 목적**: 학생 정보를 입력하면 중퇴 위험 확률과 주요 위험 요인을 즉시 제공

### 문제 재정의

원래 데이터셋의 Target은 Dropout / Graduate / Enrolled 3개 클래스로 구성된다. 그러나 **Enrolled(재학중)는 아직 결과가 확정되지 않은 학생**으로, 학습 데이터로 사용할 경우 라벨 노이즈가 발생한다. 이에 Enrolled를 제외하고 **Dropout vs Graduate 이진 분류 문제로 재정의**하였다.

| 구분 | 학생 수 | 비율 |
|------|--------|------|
| Graduate (졸업) | 2,209명 | 49.9% |
| Dropout (중퇴) | 1,421명 | 32.1% |
| Enrolled (재학중, 제외) | 794명 | 17.9% |
| **학습 데이터 합계** | **3,630명** | - |

### EDA 주요 발견

**발견 1 — 1학기 성적이 중퇴 예측의 핵심 신호**

중퇴 학생과 졸업 학생의 1학기 평균 성적을 비교한 결과 뚜렷한 차이가 확인됐다.

| 그룹 | 1학기 평균 성적 |
|------|--------------|
| 중퇴 (Dropout) | 7.3점 |
| 졸업 (Graduate) | 12.6점 |

졸업 학생이 중퇴 학생보다 약 **1.7배 높은 성적**을 보였다. 입학 첫 학기 성적만으로도 중퇴 위험을 조기에 식별할 수 있음을 시사한다.

**발견 2 — 학비 납부 여부가 중퇴율에 결정적 영향**

| 그룹 | 학비 미납 비율 |
|------|-------------|
| 중퇴 (Dropout) | 32.2% |
| 졸업 (Graduate) | 1.3% |

중퇴 학생 중 학비 미납 비율이 졸업 학생 대비 약 **25배 높게** 나타났다. 재정적 어려움이 중퇴와 강하게 연관됨을 확인하였다.

**발견 3 — 결측값 없음**

전체 37개 컬럼 모두 결측값이 존재하지 않아 별도의 결측치 처리는 수행하지 않았다.

### 이상치 처리

수치형 연속 변수(성적, 이수 과목 수 등)에서 일부 극단값이 관찰됐으나 실제 가능한 범위 내의 값으로 판단하여 제거하지 않았다. 결측값 대신 0으로 채우는 방식(`fillna(0)`)을 학습 전처리 단계에서 적용하였다.

## 4. 모델 / 서비스

### 사용 알고리즘

**Random Forest Classifier** (scikit-learn)

- `n_estimators=100`, `random_state=42`, `n_jobs=-1`
- **선택 이유**: 비선형 관계와 변수 간 상호작용을 잘 포착하며, 학생 중퇴 예측 관련 연구에서 높은 성능이 검증된 알고리즘
- **학습/테스트 비율**: 80% / 20% (stratified split)

### 입력 → 출력 흐름

```
사용자 입력 (19개 변수)
        ↓
  결측값 처리 (fillna(0))
        ↓
Random Forest 예측
        ↓
중퇴 확률 / 졸업 확률 출력
        ↓
주요 위험 요인 안내
```

### 성능 지표

| 지표 | 값 |
|------|---|
| 정확도 (Accuracy) | **89.9%** |
| 균형 정확도 (Balanced Accuracy) | **88.5%** |
| 중퇴 F1-score | **86.0%** |
| 졸업 F1-score | **92.0%** |

> **균형 정확도를 추가한 이유**: 중퇴(1,421명) vs 졸업(2,209명)의 클래스 불균형이 존재하여 단순 정확도만으로는 다수 클래스에 편향된 평가가 될 수 있다. 균형 정확도는 각 클래스 정확도의 평균으로 불균형 데이터에서 더 신뢰할 수 있는 지표이다.

## 6. 결론 & 한계

### 알게 된 것

- 포르투갈 고등교육 학생 데이터만으로 중퇴 위험을 **정확도 89.9%** 로 예측할 수 있었다.
- **성적과 이수 과목 수** (1·2학기)가 중퇴 예측에 가장 결정적인 요인이었다.
- **학비 납부 여부**가 성적 다음으로 강력한 예측 변수로, 재정 지원이 중퇴 예방의 핵심임을 확인했다.
- Enrolled 클래스를 제외하고 이진 분류로 재정의하는 것이 모델 성능과 서비스 실용성 측면에서 더 적합하였다.
